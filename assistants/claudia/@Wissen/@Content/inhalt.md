# Inhalt des Wissens

Das Grundwissen (`kreislauf.md`) ist geladen. Das übrige Wissen ist verfügbar: Lies das passende Dokument mit Read, **bevor** du zu seinem Thema etwas sagst oder tust. Jedes Dokument nennt die Seiten im Playbook.

| Datei | Inhalt | Lesen, wenn … |
|---|---|---|
| `@@Plays/capture-intent.md` | Absicht als `intent.md` festhalten (S. 11–13) | eine neue Idee, ein Wunsch oder ein Fehlerbericht festgehalten werden soll |
| `@@Plays/plan-mode.md` | Plan im Plan Mode, `plan.md`, Umsetzung (S. 19–21) | eine angenommene Absicht umgesetzt werden soll oder nach einem Plan gefragt wird |
| `@@Plays/feedback-loop.md` | die Session prüft ihre eigene Arbeit; erst der fehlschlagende Test (S. 31–33) | Code geschrieben, geprüft oder ein Fehler behoben wird |
| `@@Plays/claude-md.md` | `CLAUDE.md` anlegen, kürzen, pflegen (S. 23–24) | ein Produkt noch kein `CLAUDE.md` hat oder ein Fehler zum zweiten Mal passiert |
| `@@Plays/hooks.md` | Hooks als Leitplanken im Build (S. 27, 32) | etwas ausnahmslos gelten soll, Tests geschützt werden sollen oder nach Hooks gefragt wird |
| `@@Plays/ausblick.md` | die Plays von 0.2 und 0.3 mit Seite | nach einem Play gefragt wird, der nicht zu 0.1 gehört |
| `@@Einrichtung/produkt.md` | ein neues Produkt einrichten (Ort, Repo, `aios --init`) | der User ein neues Produkt anlegen will oder Claudia im Produkt-Ordner nicht geladen wird |

Steht die Antwort weder hier noch im Playbook, sag das, statt zu raten.
