# Inhalt des Wissens

Das Grundwissen (`kreislauf.md`) ist geladen. Das übrige Wissen ist verfügbar: Lies das passende Dokument mit Read, **bevor** du zu seinem Thema etwas sagst oder tust. Jedes Dokument nennt die Seiten im Playbook.

| Datei | Inhalt | Lesen, wenn … |
|---|---|---|
| `@@Plays/capture-intent.md` | Absicht als `intent.md` festhalten, Vorlage, `/claudia-intent` (S. 11–13) | eine neue Idee, ein Wunsch oder ein Fehlerbericht festgehalten werden soll |
| `@@Plays/skills.md` | Skills des Produkts, Vorgaben als Skills, Auslösen prüfen (S. 25–26) | Wissen uneinheitlich angewandt wird, Vorgaben aufgenommen oder geändert werden oder nach Skills gefragt wird |
| `@@Plays/requirements-design.md` | aus `intent.md` ein `spec.md` mit Vorgaben und Bedenken, `/claudia-spec` (S. 15–17) | ein `intent.md` angenommen ist oder nach Anforderungen, Entwurf oder Spec gefragt wird |
| `@@Plays/plan-mode.md` | Plan im Plan Mode, `plan.md`, Teilen in Aufgaben, Umsetzung (S. 19–21) | eine angenommene Absicht oder Spec umgesetzt werden soll oder nach einem Plan gefragt wird |
| `@@Plays/parallel-subagents.md` | parallele Sessions in Worktrees, Zusammenführen, Subagents wie `verifier` (S. 27–29) | Arbeit parallel laufen soll, eine Aufgabe sich wiederholt oder nach Subagents gefragt wird |
| `@@Plays/feedback-loop.md` | die Session prüft ihre eigene Arbeit; erst der fehlschlagende Test; Sichtprüfung bei UI (S. 31–33) | Code geschrieben, geprüft oder ein Fehler behoben wird |
| `@@Plays/claude-md.md` | `CLAUDE.md` anlegen, kürzen, pflegen (S. 23–24) | ein Produkt noch kein `CLAUDE.md` hat oder ein Fehler zum zweiten Mal passiert |
| `@@Plays/hooks.md` | Hooks als Leitplanken: Tests schützen, Hook für `plan.md`, geprüfte Skripte (S. 20, 27, 32) | etwas ausnahmslos gelten soll, Tests geschützt werden sollen oder nach Hooks gefragt wird |
| `@@Plays/evals.md` | Evals lokal: Format, Läufer, Log, Gate, `/claudia-evals` (S. 34–35) | eine Änderung abgeschlossen ist, ein Fehler behoben ist, ein Commit `CLAUDE.md` oder `.claude/` berührt oder nach Evals gefragt wird |
| `@@Plays/ausblick.md` | die Releases 0.3 bis 1.0 mit Plays und Seiten | nach einem Play gefragt wird, der nicht zu 0.2 gehört |
| `@@Einrichtung/produkt.md` | ein neues Produkt einrichten, Trennung der Skills, Umstellung aus 0.1 | der User ein neues Produkt anlegen will, ein Produkt aus 0.1 hat oder Claudia im Produkt-Ordner nicht geladen wird |

Steht die Antwort weder hier noch im Playbook, sag das, statt zu raten.
